# 📊 Analisis & Visualisasi Data Penjualan (Python)

Proyek ini dibuat sebagai bentuk latihan *hands-on* analisis data dasar menggunakan **Python**, **Pandas**, dan **Matplotlib** di lingkungan Kaggle Notebook.

---

## 🛠️ Tools & Library
* **Language:** Python
* **Data Manipulation:** Pandas
* **Data Visualization:** Matplotlib
* **Environment:** Kaggle Notebook

---

## 💡 Fitur & Alur Kerja
1. **Penyusunan Data:** Membuat DataFrame sederhana yang memuat informasi produk, harga, dan jumlah unit terjual.
2. **Kalkulasi Data:** Menhitung total omzet per transaksi (`harga * jumlah_terjual`).
3. **Agregasi & Visualisasi:**
   * **Bar Chart:** Membandingkan total omzet penjualan antar jenis produk (Kopi, Teh, Roti).
   * **Pie Chart:** Menganalisis proporsi kontribusi omzet tiap produk terhadap total keseluruhan.
